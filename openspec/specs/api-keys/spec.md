# api-keys Specification

## Purpose

Authenticate producer services with API keys and isolate every resource by owning key. Keys are stored as hash + display prefix only, and the raw key is shown exactly once.

Planned coverage: FR-AUTH-001 (create key via CLI), FR-AUTH-002 (Bearer auth, 401), FR-AUTH-003 (tenant isolation), NFR-SEC-001 (hashed at rest).

## Requirements

_None yet. Requirements are added by the change that implements this capability._
